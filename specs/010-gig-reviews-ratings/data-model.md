# Data Model: Puntuación y Comentarios de Gigs

**Feature**: Puntuación y Comentarios de Gigs  
**Date**: 2026-07-10  
**Spec**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

## Entities

### Opinion (Review)

Representa la puntuación y comentario que un cliente deja sobre un Gig tras la entrega de un pedido.

| Field | Type | Required | Validation | Notes |
|-------|------|----------|------------|-------|
| id | string | system | Auto-generated by repository | Identificador único de la reseña |
| cliente | string | yes | Non-empty string | ID del cliente autor |
| gig | string | yes | Non-empty string | ID del Gig reseñado |
| pedido | string | yes | Non-empty string | ID del pedido entregado asociado |
| puntuacion | integer | yes | 1 ≤ puntuacion ≤ 5 | Escala numérica de estrellas |
| detalle | string | yes | Non-empty after trim, max 1000 chars | Comentario escrito |
| fechaCreacion | string (ISO 8601) | system | Assigned on creation | Fecha/hora de publicación |

**Business rules**:
- Una reseña solo puede crearse si el pedido asociado está en estado `Entregado`.
- No puede existir más de una reseña para el mismo `pedido`.
- No se permite editar ni eliminar una reseña en esta versión.

### Pedido (Order)

Gatilla la posibilidad de dejar una reseña. La relación es 1 pedido → 0..1 reseña.

| Field | Type | Notes |
|-------|------|-------|
| id | string | Identificador del pedido |
| cliente | string | ID del cliente comprador |
| gig | string | ID del Gig contratado |
| estado | string | Debe valer `'Entregado'` para permitir reseña |
| puntuacion | number | Campo heredado; NO se utiliza para la reseña de esta feature |

**Relationship to Opinion**:
- Pedido.opiniones no se mantiene como lista en el dominio; se consulta vía `OpinionRepository.findByPedidoId`.

### Gig

El servicio al que se asocian las reseñas. Los atributos de rating son derivados (calculados), no persistentes.

| Field | Type | Notes |
|-------|------|-------|
| id | string | Identificador del Gig |
| vendedor | string | ID del freelancer propietario |
| nombre | string | Título del servicio |

**Derived fields**:
- `rating` (number): promedio de `puntuacion` de todas las opiniones del Gig, con 1 decimal.
- `reviewCount` (integer): cantidad total de opiniones del Gig.

**Business rules**:
- Si el Gig no tiene opiniones, `rating` es `0` y `reviewCount` es `0`.
- El promedio se recalcula cada vez que se solicita el Gig o su listado de reseñas.

## State Transitions

```text
Pedido: ... → Entregado → [Review created once] → Opinion exists
```

No hay transiciones de estado en `Opinion`; es inmutable tras la creación.

## Validation Matrix

| Action | Condition | Result |
|--------|-----------|--------|
| Create review | Pedido no existe | 404 Not Found |
| Create review | Pedido no está en `Entregado` | 400 Bad Request |
| Create review | Pedido ya tiene review | 409 Conflict |
| Create review | `puntuacion` fuera de 1..5 | 400 Bad Request |
| Create review | `detalle` vacío o > 1000 chars | 400 Bad Request |
| Create review | Cliente no es el comprador del pedido | 403 Forbidden |
| Get reviews for Gig | Gig no existe | 404 Not Found |
| Get reviews for Gig | Sin reseñas | 200 con lista vacía |

## Key Design Decisions

- `Opinion` almacena `pedido` para garantizar la regla de una reseña por pedido.
- El cálculo del promedio vive en `GigService` / `OpinionService` para evitar duplicación de datos en `Gig`.
- `Pedido.puntuacion` heredado no se usa para esta feature; la calificación se persiste en `Opinion`.
